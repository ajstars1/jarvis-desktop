# dotfiles

The Hyprland side of jarvis-desktop: window manager config, title bars, snapping, minimize/maximize helpers, top bar, launcher themes, notifications and lock screen. See the [main README](../README.md) for what it all does and how to install it.

`install.sh` symlinks these folders into `~/.config`, after backing up anything it would replace into `~/.dotfiles-backup/<timestamp>/`.
